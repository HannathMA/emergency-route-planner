🎯 Algorithmic Conclusion:

✓ A* Search: Evaluates both actual highway distance $g(n)$ and straight-line Euclidean distance $h(n)$ to Aster Medcity, guaranteeing the mathematically optimal lowest-cost arrival.
✓ BFS: Explores by junction levels; guarantees the fewest junction crossings but is blind to road lengths.
✓ Greedy Best-First: Considers only straight-line distance $h(n)$; fast but vulnerable to detour traps when congested highways intervene.
✓ DFS / IDDFS: Explore deep corridors with minimal memory footprints, with IDDFS guaranteeing shallowest-hop recovery without excessive space consumption.
